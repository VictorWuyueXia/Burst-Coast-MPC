# Rotary-Pendulum PPO Preliminary Results: Interpretation Summary

## Judgment

The first PPO agent is not yet a working controller. Sixteen trials across two
eight-GPU sweeps produced zero strict swing-up-and-hold successes.

The short sweep learned enough energy but rotated through upright at high speed. The
longer sweep learned a safer but under-powered oscillation. A separate tight-box test
also showed zero 0.25 s local-balance success for every final checkpoint. The missing
capability is upright capture, not raw energy acquisition.

## Design consequence

Keep the current 8,963-parameter shared-encoder actor-critic. Optimization was stable,
and a larger network would optimize the same misaligned objective.

Repair the reward before another large sweep:

1. normalize local state errors by the actual 0.05 goal tolerances;
2. use discount-consistent potential shaping;
3. scale per-step regularizers by elapsed time;
4. prevent curriculum advancement until strict local capture passes a fixed validation
   set.

Only if the repaired local PPO still fails should the upright linearization provide an
LQR teacher for actor pretraining. Do not yet use these critics as MPC terminal values.

The full numerical evidence, formulas, and milestone gates are in
`6.5-rotary-pendulum-PPO-preliminary-results.md`.
