1. Set JAX arm range to ±135 degrees. Integrate each existing 20 ms observation/goal interval with ten 2 ms RK4 substeps, preserving 100 ms held actions. Add explicit hold length and continuation controls. Pass: reference integration parity, correct hold reset and nonfrozen post-capture motion, correct arm-bound detection; original one-second goal remains the default.
2. Test actual heuristic without stopping at first success, across motor caps and arm penalties, for 120–300 s from downward and near-upright starts. Compare 40/120/300 s prefixes of the same physical rollout, not different deadline-conditioned teacher behavior. Finite evidence never proves indefinite stability.
3. If the teacher balances for longer, retain those real transitions as demonstrations. Compare matched short-hold versus long-hold data and RL arm penalties; use a ten-second training hold and 120 s deadline, then test post-success continuation. Pass: cap/arm/integration/goal-matched data, episode-disjoint splits, real feedback after capture, fresh held-out sustained and bounded success. Inspect first round before a second parameter iteration. If the original teacher fails, report that fact and test a clearly labeled local linear balancing augmentation rather than attributing it to the original heuristic.
4. Explain soft costs versus hard guarantees and diagnose weak-motor failures using long-horizon statistics, state/torque records and constrained local controllability tests. Pass: bilingual shallow human report with plots, detailed machine records, appropriate tests and released GPUs.
