# Interpretation Summary for 5.7.1

## Main judgment

Use model-based graph dynamic programming as the reference Bellman solution. The present pendulum has known deterministic dynamics and a finite timing-action grid, so actor-critic is unnecessary.

The practical sequence is:

1. Generate complete same-state, different-action transitions with the current MPC.
2. Solve the finite transition graph backward from the goal.
3. Test the table directly.
4. Distill it into a neural $Q(s,B,H)$ only if the table is too large or too slow, where $s$ is the decision state, $B$ is burst length, and $H$ is total event horizon.

The existing Monte Carlo episodes remain useful for finding relevant states. Their return-cost labels must not be treated as optimal because later horizons were chosen randomly.

## Important correction

Do not train only when the neural prediction is above the dynamic-programming target. That leaves underestimated actions falsely cheap, which is especially dangerous because deployment chooses the minimum predicted cost. Fit every Bellman target in both directions.

The proposed method is fitted value or Q iteration, not actor-critic. There is no learned actor: the policy is the explicit minimum over the finite $(B,H)$ grid.

## Horizon decision

The monotone-binary formulation is not the recommended online path. It replaces one burst boundary with one binary variable per physics step, requires a mixed-integer nonlinear solver, and has only $H+1$ feasible prefix patterns that can already be enumerated directly.

The lowest-risk timing baseline is parallel fixed-anchor IPOPT. If it remains too slow, try a bounded model predictive path integral (MPPI) prototype with:

- a small set of fixed $(B,H)$ anchors;
- batched exact RK4 rollouts;
- exact zero-torque coast masks;
- the DP-trained value as terminal cost;
- exact re-evaluation or IPOPT refinement of the best few candidates.

MPPI is the more promising of the user's two new directions, but it should be compared against parallel continuous enumeration rather than against the current serial controller.

## Validation boundary

The learned result is only Bellman-optimal on the declared finite abstraction. Continuous-state discretization, interpolation, a finite timing grid, local IPOPT torque solutions, and model mismatch remain approximation sources.

Success requires stable results under state/action refinement, independent Bellman-residual checks, same-state action-regret tests, held-out deterministic closed-loop episodes, and increasing MPPI sample budgets.
