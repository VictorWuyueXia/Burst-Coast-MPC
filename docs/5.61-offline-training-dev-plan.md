# Offline Structured Critic Training Plan

## Summary
- Implement only design Steps 1-5 under `scripts/offline-training/`; do not touch `Coordinator`, MPC controllers, simulation, or `wsmpc` CLI.
- Train the structured residual critic from `rl_steps.csv` using logged `return-cost`; fit `lambda_t`, `lambda_u`, and `lambda_c` jointly with the residual MLP.
- Do not implement `hat t_solve(B,H)` or any `alpha/beta` solve-time model. Training uses logged `solve-time-s / timestep-s` for each dataset row.
- Step 5 will be observed-row validation only: no full-grid compute-aware policy selection until solve-time modeling is added.

## Key Changes
- Add `configs/offline-training/config.yaml` with only:
  `data-roots`, `output-root`, `run-name`, `seed`, `train-fraction`, `batch-size`, `max-epochs`, `learning-rate`, `action-grid-count`.
- Add dependency entries for `torch` and `pytorch-lightning`; leave CUDA wheel selection to the GPU workstation install path.
- Save snapshots under `artifacts/model-snapshots/<run-name>_<timestamp>/`:
  `config.json`, `model_structure.txt`, `lambda.json`, `normalization.json`, `metrics.json`, `critic_state_dict.pt`, Lightning checkpoints, validation CSVs, and diagnostic figures.
- Keep code comments as concise one-liners before key blank-line-separated logic blocks; no “stage”, progress-version, fallback, or dev-temporary wording.

## Data And Model Details
- Required CSV columns stay exactly alias-based: `s-sin-theta`, `s-cos-theta`, `s-omega-rad-s`, `bbar`, `hbar`, `burst-steps`, `horizon-steps`, `return-cost`, `solve-time-s`, `done`, `plan-id`.
- Read each run’s `config.json` by explicit keys only: pendulum constants, `timestep-s`, and data-generation cost weights. Extra historical keys are ignored; missing required keys fail directly.
- Feature tensor is `[sin(theta), cos(theta), omega / omega_ref, e_E, bbar, hbar]`, with `omega_ref = 2 * sqrt(g / l)` and `e_E = (E - E*) / E*`.
- Fit residual input mean/std on training rows only; save the statistics for later deployment.
- Physical feature tensor is `[horizon_steps * timestep_s, solve_time_s / timestep_s, burst_steps]`.
- `Q_phys = lambda_t * duration + lambda_c * compute_steps + lambda_u * burst_steps`; lambdas are `softplus(eta)` and initialize from positive data-generation weights.
- Split by artifact run directory using `train-fraction`; do not split individual rows from the same run across train/validation.

## Execution And Verification
- Implementation order:
  1. Add dependencies and `configs/offline-training/config.yaml`.
  2. Build dataset loading, vectorized feature construction, run-level split, and normalization save path.
  3. Build the PyTorch Lightning structured critic and lambda logging.
  4. Build training orchestration with hardcoded `accelerator="gpu"`, `devices=1`, `precision="32-true"`, and concise terminal prints.
  5. Build diagnostics and HOW-TO.
- Terminal logs only:
  `offline-training load ...`, `offline-training train ...`, `offline-training finish ...`, `offline-training snapshot_dir=...`.
- Test scenarios:
  - Synthetic two-run artifact fixture verifies required columns, run-level split, energy feature, and train-only normalization.
  - Model unit verifies output shape, finite loss, positive lambdas, and absence of solve-time fit parameters.
  - One-epoch GPU smoke run verifies checkpoint, `lambda.json`, `metrics.json`, and `critic_state_dict.pt`.
  - Real artifact run verifies validation MSE, physical-only MSE, observed-row sanity CSV, and Q-surface figures.
- Local Mac verification can compile/read code, but real training is expected to fail loudly without CUDA.

## Assumptions
- The implementation follows the repo style rule strictly: compact files, no thin wrappers, no unnecessary CLI/config surface, no fallback behavior, no `try/except`, and no ordinary file-I/O `with` blocks.
- `artifacts/` remains ignored by git, so model snapshots are generated outputs.
- Full compute-aware grid policy validation is deferred because unexecuted grid candidates do not have real measured solve time when solve-time fitting is excluded.
