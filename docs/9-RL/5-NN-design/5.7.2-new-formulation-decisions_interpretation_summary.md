# Interpretation Summary for 5.7.2

## Main judgment

Learn only the replanning horizon $H$. For each candidate $H$, let the inner controller determine the monotone enable cutoff $B$ and continuous feasible torque. Implement the binary-prefix formulation through parallel fixed-$(B,H)$ continuous solves, which exactly enumerate its finite masks without creating a nonlinear mixed-integer program.

Use one variable-amplitude enabled prefix followed by a nonempty exact-zero coast in every event. Apply weak positive torque-magnitude and torque-change penalties: prefer minimum sufficient torque, not saturation. A positive enabled-duration term is still necessary; otherwise longer burst prefixes can reproduce shorter ones by assigning zero to the extra torque slots, so $B$ is not identifiable.

## Solver judgment

Parallel deterministic MPC is the reference. Add an $H$-only Bellman critic only after exact horizon selection is a measured bottleneck. Evaluate fixed-horizon MPPI for continuous torque sampling or CEM for categorical $(B,H)$ sampling. Continuous two-phase free-duration optimization is the cleanest future direction for determining horizon inside one smooth nonlinear program.

MPPI must not replace constrained MPC, the authoritative Bellman-label generator, or the deployed horizon scheduler. Its useful role is auxiliary: generate torque/cutoff proposals, warm-start MPC, screen candidates, and find difficult states. Every accepted training edge must still pass constrained MPC refinement and deterministic rescoring. Sampling discrete soft horizons is better described as CEM or stochastic horizon screening than canonical MPPI.

## Value-function judgment

Use $Q_H(s,H)$ as the primary learned scheduler and retain joint $Q(s,B,H)$ as an ablation. Derive $V(s)=\min_H Q_H(s,H)$ and use it as MPC terminal cost. Do not terminate rollout using an absolute heuristic threshold on $V$: a principled stopping rule must compare the cost of stopping and replanning now with the cost of continuing, which is itself an action-conditioned Bellman decision.

## Global-state judgment

Do not include past activation count or an invented budget-to-go. Include only physical state, remaining episode time, goal-hold count, and—when the event can end at nonzero torque—the previous applied torque. Add remaining activation budget only after a real physical or mission cap is declared.

## Validation judgment

The decisive comparisons are exhaustive parallel $(B,H)$ search versus $H$-only and joint $(B,H)$ critics, followed by deterministic MPC versus MPPI/CEM. Judge them by feasibility, goal-and-hold completion, same-state regret, event count, completion time, torque use, and median and 95th-percentile planning latency.
