# How to read the figure plan

Read [outline.md](outline.md) for the proposed elements and layout of the three figures. The sequence is physical configuration → energy request and physical compatibility → torque-dependent endpoint prediction and selection.

The most important distinction is between a physically realizable energy state and an endpoint reachable from the current state under one bounded held torque. Work-matching candidates and the controller's selected action also need different markers.

The existing recorded diagnostic is a useful shared example for Figures 2 and 3: it contains two reported work matches and a different logged selected torque. Its requested plane lies below upright-rest total energy. Its small work request must not be enlarged for visual effect.

The [mathematical contract](machine-scannables/mathematical_contract.md) records the exact geometry, set parameterization, implementation mapping, and checks needed before rendering. This deliverable contains plans only. No figure was rendered, no controller simulation was rerun, and the manuscript was not edited.
