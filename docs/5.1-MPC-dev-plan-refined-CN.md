# Wake Sleep MPC 交接报告

## 0. 当前实现决策

本文档是确定性摆杆基准当前的工程交接说明。

当前开发目标为：

1. 仅使用 MPC。
2. 使用离散预测映射。
3. 固定总预测时域。
4. 预测时域等于被动自然周期的一半。
5. 从小规模有限比例集合中选择 burst 与 coast 的划分。
6. coast 动作固定为零。
7. 不使用学习型 Q critic。
8. 不实现 early wake 逻辑。
9. 构建原子化 MPC 模块，并支持热插拔的代价与约束规格文件。

当前仓库文档已经定义了更大的研究目标：wake sleep 控制、显式 burst coast 结构、非线性摆杆基准、能量整形代价、作为未来终端值的学习型 Q critic，以及作为未来鲁棒性机制的 early re-planning。本文档将该整体设计收敛为第一个可求解的实现阶段。

## 1. 连续预测与离散预测

MPC 问题使用离散预测模型。

连续动力学仍应作为物理模型存在，但 MPC 优化器应调用离散更新映射：

```text
x_next = f_d(x, u, dt)
```

其中 `x` 为当前状态，`u` 为输入，`dt` 为固定采样时间，`f_d` 由连续动力学的 RK4 积分得到。

### 1.1 为什么离散预测更适合当前结构

控制器在采样仿真步上动作。划分比例也会变成离散步数：

```text
N_b = max(1, round(lambda N))
N_c = N - N_b
```

因此，离散预测模型与实现直接匹配。

离散 MPC 形式具有以下实际优势：

1. 优化器看到的是有限状态与输入序列。
2. 预测时域精确等于仿真器步数。
3. burst coast 划分在采样层面是精确的。
4. 输入约束可直接在实际施加的输入采样点上执行。
5. 代价是预测步上的有限和。
6. 同一个 `f_d` 可同时用于仿真 rollout 与 MPC 预测。
7. 相比连续时间 collocation，该形式更容易用 SQP 实现。
8. single shooting 很直接，因为只有 burst 输入需要作为决策变量。

### 1.2 连续预测能提供什么

连续时间最优控制形式原则上可以更精确。它可以通过 collocation 或 direct transcription 在连续区间上强制满足动力学，也能更显式地捕捉采样间约束行为。

对当前阶段而言，这些优势不值得额外实现成本。

连续预测会要求：

1. 更多决策变量。
2. 更多等式约束。
3. 更复杂的 transcription。
4. 更复杂的划分处理。
5. 更谨慎的尺度归一化。
6. 更多求解器调参。

### 1.3 决策

仅用连续动力学定义物理系统与仿真：

```text
dot(x) = f_c(x, u)
```

MPC 预测使用离散动力学：

```text
x_{i + 1} = f_d(x_i, u_i, dt)
```

对当前基准而言，离散映射至少与连续形式同样合适，因为系统维度低、时间步固定，且求解目标是现成 SQP 风格的非线性规划。

## 2. 模型约定

使用原始状态：

```text
x = [theta, omega]^T
```

其中：

1. `theta` 为摆角，单位为弧度。
2. `omega` 为角速度，单位为弧度每秒。

使用如下角度约定：

```text
theta = 0      下垂平衡点
theta = pi     直立目标
```

目标状态为：

```text
x_star = [pi, 0]^T
```

使用连续动力学：

```text
dot(theta) = omega
I dot(omega) = - m g l sin(theta) - b omega + u
```

其中：

1. `I` 为绕转轴的转动惯量。
2. `m` 为摆杆质量。
3. `g` 为重力加速度。
4. `l` 为转轴到质心的距离。
5. `b` 为粘性阻尼系数。
6. `u` 为标量扭矩输入。

实现警告：

现有仓库规格有一处将重力项符号写为正号。采用下文能量约定且目标为 `theta = pi` 时，应使用上面的负重力符号。否则被动能量一致性测试会失败。

## 3. 离散预测映射

将连续动力学实现为纯函数：

```text
f_c(x, u, params)
```

将 RK4 实现为：

```text
f_d(x, u, dt, params)
```

其中 `params` 包含 `I`、`m`、`g`、`l` 与 `b`。

所有 MPC 预测必须使用：

```text
x_{i + 1} = f_d(x_i, u_i, dt, params)
```

第一版基准不要使用 Euler 积分器，除非明确将其作为调试选项加入。

## 4. 输入限制与基准条件

使用标量扭矩边界：

```text
|u| <= u_max
```

欠驱动条件为：

```text
u_max < m g l
```

这使得直接静态抵抗重力不足以完成控制任务，迫使控制器利用能量泵入与时机选择。

## 5. 自然频率与固定预测时域

使用下垂平衡点附近的被动小角度自然频率：

```text
omega_n = sqrt(m g l / I)
```

其中 `omega_n` 为无阻尼自然角频率，单位为弧度每秒。

被动小角度周期为：

```text
T_0 = 2 pi / omega_n
```

当前阶段使用时域：

```text
T_N = 0.5 T_0
```

然后计算离散时域：

```text
N = round(T_N / dt)
```

若摆杆可视为距离 `l` 处的点质量，则：

```text
I = m l^2
omega_n = sqrt(g / l)
T_0 = 2 pi sqrt(l / g)
```

当 `l = 1 m`、`I = 1 kg m^2`、`m = 1 kg`、`dt = 0.02 s` 时：

```text
omega_n = sqrt(9.81)
omega_n = 3.13 rad/s
T_0 = 2.01 s
T_N = 1.005 s
N = 50
```

自然周期只是初始化尺度。大幅摆动与主动扭矩会改变实际时机。当前阶段不要优化总时域，将 `N` 固定为半周期。

## 6. 划分比例

使用有限划分比例集合：

```text
Lambda = {0.1, 0.2, 0.3}
```

对 `Lambda` 中每个 `lambda`，计算：

```text
N_b = max(1, round(lambda N))
N_c = N - N_b
```

其中：

1. `N_b` 为 burst 时域步数。
2. `N_c` 为 coast 时域步数。
3. `N` 为固定完整预测时域。
4. `lambda` 为 burst 到完整时域的比例。

不要将 `lambda` 作为连续 SQP 决策变量。SQP 内部的 rounding 会产生非光滑行为。应在求解器外枚举这三个划分比例。

## 7. 当前阶段的 coast 指令

第一版使用 zero coast：

```text
u_h = 0
```

配置中应显式设置：

```text
coast_mode: zero
```

第一版不要使用 `hold_last`。将 `hold_last` 保留为未来选项：

```text
coast_mode: hold_last
u_h = v_{N_b - 1}
```

原因：

zero coast 给出更干净的基线。它将主动 burst 权限与被动演化分离，也避免 coast 期间保持扭矩这一行为究竟是主动控制还是严格 sleep 的歧义。

## 8. 能量与相位特征

原始 MPC 状态仍为：

```text
x = [theta, omega]^T
```

能量与相位是代价特征。

定义动能：

```text
K(x) = 0.5 I omega^2
```

定义势能：

```text
V(x) = m g l (1 - cos(theta))
```

定义总能量：

```text
E(x) = K(x) + V(x)
```

定义直立能量：

```text
E_star = 2 m g l
```

定义归一化能量误差：

```text
e_E(x) = (E(x) - E_star) / E_star
```

选择：

```text
omega_s = sqrt(m g l / I)
```

定义相位代理：

```text
a(theta) = sin(theta / 2)
b(omega) = omega / omega_s
r(x) = sqrt(a(theta)^2 + b(omega)^2 + eps_phi^2)
c_phi(x) = a(theta) / r(x)
s_phi(x) = b(omega) / r(x)
```

其中 `eps_phi > 0` 为小的正则化常数。

定义相位误差：

```text
e_phi(x) = [c_phi(x) - 1, s_phi(x)]^T
```

定义 wrap 后的直立角度误差：

```text
e_theta(x) = atan2(sin(theta - pi), cos(theta - pi))
```

定义局部直立误差：

```text
e_loc(x) = [e_theta(x), omega / omega_s]^T
```

定义能量门控：

```text
w_E(x) = exp( - e_E(x)^2 / sigma_E^2 )
```

其中 `sigma_E > 0` 控制相位与局部稳定化何时开始起作用。

## 9. 能量相位值函数候选

使用以下值函数候选作为主要状态代价：

```text
V_ep(x) =
    q_E e_E(x)^2
  + q_phi w_E(x) e_phi(x)^T Q_phi e_phi(x)
  + q_loc w_E(x) e_loc(x)^T Q_loc e_loc(x)
```

其中：

1. `q_E > 0` 为能量权重。
2. `q_phi >= 0` 为相位权重。
3. `q_loc >= 0` 为局部直立稳定化权重。
4. `Q_phi` 为正定矩阵。
5. `Q_loc` 为正定矩阵。
6. `w_E(x)` 为能量门控。

调参顺序：

1. 先只使用能量项。
2. 加入局部直立稳定化。
3. 加入饱和偏好。
4. 加入相位代理代价。

不要同时调节所有项。

## 10. Burst、coast 与终端代价

对 burst 输入 `u`，定义归一化输入：

```text
s = u / u_max
```

使用 burst 阶段代价：

```text
ell_b(x, u, u_prev) =
    V_ep(x)
  + rho_sat (1 - (u / u_max)^2)^2
  + rho_du ((u - u_prev) / u_max)^2
```

其中：

1. `rho_sat >= 0` 权衡 burst 期间的近饱和偏好。
2. `rho_du >= 0` 权衡输入平滑性。
3. `u_prev` 为上一时刻已施加输入。

对当前 zero coast 模式：

```text
ell_c(x) = V_ep(x)
```

第一版不要加入 coast 输入惩罚，因为：

```text
u_h = 0
```

使用终端代价：

```text
ell_f(x_N) = q_f V_ep(x_N)
```

其中 `q_f > 0` 为终端代价权重。

## 11. 单个划分候选的 MPC 问题

在决策时刻 `k`，读取测得状态：

```text
x_tk
```

对 `{0.1, 0.2, 0.3}` 中每个 `lambda`，求解：

```text
J_star(x_tk, lambda) =
min over v_0, ..., v_{N_b - 1}
[
    sum_{i = 0}^{N_b - 1} ell_b(x_i, v_i, v_{i - 1})
  + sum_{j = 0}^{N_c - 1} ell_c(x_{N_b + j})
  + ell_f(x_N)
]
```

约束为：

```text
x_0 = x_tk
```

Burst 动力学：

```text
x_{i + 1} = f_d(x_i, v_i, dt, params)
for i = 0, ..., N_b - 1
```

Coast 动力学：

```text
x_{N_b + j + 1} = f_d(x_{N_b + j}, 0, dt, params)
for j = 0, ..., N_c - 1
```

输入约束：

```text
|v_i| <= u_max
for i = 0, ..., N_b - 1
```

可选状态边界：

```text
x_i in X
for i = 0, ..., N
```

其中 `X` 为允许状态集。

选择：

```text
lambda_star = argmin over lambda in Lambda of J_star(x_tk, lambda)
```

仅施加被选中的计划：

```text
u_{t_k + i} = v_i_star
for i = 0, ..., N_b_star - 1
```

随后使用零输入 coast：

```text
u_{t_k + i} = 0
for i = N_b_star, ..., N - 1
```

然后在下一个决策时刻再次运行 MPC。

## 12. 当前阶段不实现 early wake

当前阶段忽略 early wake 逻辑。

执行序列固定为：

```text
burst for N_b_star steps
coast for N_c_star steps
then re solve
```

暂不实现预测偏差触发、状态裕度触发或 Q degradation 触发。

这会让第一个基准更容易调试，并使 burst coast 调度在没有额外事件逻辑的情况下清晰可观察。

## 13. SQP 实现建议

先使用 single shooting。

决策变量为：

```text
V = [v_0, v_1, ..., v_{N_b - 1}]^T
```

所有状态都通过 `f_d` 前向 rollout 生成。

这能保持优化问题规模较小。

让问题对 SQP 友好：

1. 在每个子问题内固定 `N`、`N_b` 和 `N_c`。
2. 在求解器外枚举 `lambda`。
3. 使用平滑代价项。
4. 避免使用 `|u| >= eta_u u_max` 这样的硬下界。
5. 避免在代价中使用绝对值。
6. 避免在连续目标中使用 `round`、`if`、`min` 或 `max`。
7. 对能量、速度和输入进行归一化。
8. 若维度匹配，用上一被选划分的解 warm start 当前求解。
9. 若维度不匹配，截断或填充上一输入序列。

推荐求解器路径：

1. 若速度不是关键，第一版原型使用 scipy SLSQP。
2. 形式稳定后，迁移到 CasADi 搭配 IPOPT 或 SQP 风格方法。
3. 将求解器接口隔离在 MPC 模块内部。

加入合适的logger汇报运行状态。

文件：

```text
mpc/split_ratio_mpc.py
```

### 14.4 预测 rollout 模块


职责：

## 15. 可热插拔的代价与约束规格

为代价与约束实现独立 specification 文件。

文件：

```text
specs/energy_phase_pendulum.py
```

该文件定义 MPC 使用的代价与约束。

必要接口：

```text
class CostConstraintSpec:
    def features(self, x, params):
        ...

    def value_candidate(self, x, params):
        ...

    def burst_stage_cost(self, x, u, u_prev, params):
        ...

    def coast_stage_cost(self, x, params):
        ...

    def terminal_cost(self, x, params):
        ...

    def input_constraints(self, u, params):
        ...

    def state_constraints(self, x, params):
        ...
```

MPC 模块只调用该接口。因此，未来的代价与约束设计可以在不重写优化器的情况下替换进来。


不要将求解器逻辑放入 spec 文件。spec 文件只定义数学函数。

## 17. 执行循环

在每个决策时刻：

1. 读取当前状态 `x_tk`。
2. 根据配置计算自然频率与固定时域 `N`。
3. 对 `{0.1, 0.2, 0.3}` 中每个划分比例：
  1. 计算 `N_b` 与 `N_c`。
  2. 用 SQP 求解 burst 输入序列。
  3. rollout zero coast。
  4. 计算完整时域代价。
4. 选择目标函数最小的划分。
5. 施加 burst 输入序列。
6. 对剩余步数施加 zero coast。
7. 记录轨迹、划分比例、求解器状态、能量与代价。
8. 在下一个计划决策时刻重复。

当前阶段不使用 early wake 触发器。

## 18. 调参前所需测试

### 18.1 能量一致性

当：

```text
u = 0
b = 0
```

时，短时仿真中的能量应近似保持常数。

期望：

```text
max |E(t) - E(0)| < tolerance
```

若该测试失败，检查重力符号与 RK4 实现。

### 18.2 离散模型形状

对输入状态形状 `(2,)`，`f_d` 应返回形状 `(2,)`。

### 18.3 自然周期时域

给定模型参数与 `dt`，验证：

```text
N = round(0.5 * (2 pi / omega_n) / dt)
```

### 18.4 划分比例维度

对每个划分比例：

```text
N_b >= 1
N_c >= 0
N_b + N_c = N
```

### 18.5 Zero coast rollout

burst 段结束后，所有预测 coast 输入都应等于零。

### 18.6 目标附近代价

在：

```text
theta = pi
omega = 0
```

处，`V_ep` 应接近零。

### 18.7 输入边界

所有优化得到的 burst 输入必须满足：

```text
|v_i| <= u_max
```

## 19. 需要记录的指标

每个 episode 记录：

1. 初始状态。
2. 最终状态。
3. 时间步。
4. 完整状态轨迹。
5. 完整输入轨迹。
6. 能量轨迹。
7. 每个决策时刻选择的划分比例。
8. `N`、`N_b` 与 `N_c`。
9. 每个划分候选的目标函数值。
10. 求解器成功标志。
11. 求解时间。
12. 目标进入时间。
13. 目标保持成功与否。
14. 总代价。
15. 非零控制步比例。
16. 饱和控制步比例。

对 zero coast 模式，非零控制比例应能直接体现 burst coast 模式。

## 20. 暂缓特性

第一版不要实现以下内容：

1. 学习型 Q critic。
2. 学习型值函数。
3. Hold last coast 模式。
4. Early wake 触发器。
5. 分段线性模型。
6. 模型失配。
7. 过程噪声。
8. CLBF 约束。
9. 多节点架构。
10. 并行 MPC 求解。
11. 航天器基准。

## 21. 未来扩展路径

确定性 zero coast split ratio MPC 工作后：

1. 启用 `hold_last` 作为替代 coast 模式。
2. 加入 early wake 触发器。
3. 加入学习型终端 Q 值。
4. 用 Q 终端评分替换显式终端代价。
5. 加入基于 `V_ep` 的 CLBF 约束。
6. 加入噪声与模型失配。
7. 加入航天器风格 burst coast 基准。

终端评分应已经被隔离为可互换组件：

```text
terminal_score = terminal_cost_spec.evaluate(...)
```

当前阶段：

```text
terminal_score = q_f V_ep(x_N)
```

未来学习型 Q 阶段：

```text
terminal_score = alpha_Q Q_theta(x_{N_b}, u_h, N_c)
```

该接口可避免未来学习模块迫使 MPC 求解器重写。
