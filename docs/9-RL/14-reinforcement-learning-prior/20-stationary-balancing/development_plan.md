# Stationary continuous balancing: formulation and bounded structure

Use compact task-oriented files of 40–300 lines, no new classes, thin wrappers, fallbacks, unnecessary CLI options or exception scaffolding. Preserve historical contracts and artifacts. This is a formulation experiment, not a product patch. Disclose every subsequent change to the formulation before running it.

## Milestones and validation

1. Implement a five-feature physical-state actor and critic, discounted continuing TD3, no success termination, and bootstrapping through time-limit truncations. Reward is stationary and penalizes squared normalized torque. Pass: state-identical observations/rewards independent of clock/hold memory; correct truncation targets; cap compliance and reward reconstruction tests; historical tests remain passing.
2. Keep the successful augmented teacher unchanged. Generate 120-second real trajectories from downward, capture, outward-moving arm-braking and perturbed-upright initial states at 4.59 and 2.295 mN m. Retain fully compliant trajectories that settle, measure rejection by initial-state group, and split whole episodes. Balance swing/capture/braking/recovery/quiet transition categories, with episode identifiers preserved. Pass: finite traces, cap-matched data, reconstruction agreement, disjoint splits; report teacher feasibility instead of silently changing difficult starts.
3. First eight-GPU training wave compares torque cost, imitation strength and architecture with matched data and seeds; each run has behavior cloning plus one million TD3 transitions. Inspect full-duration validation, including pretrained models, before selecting a second bounded parameter wave. Pass: finite learning, complete logs, continuing evaluation and measured torque effort. A failed formulation is an admissible result; do not add hidden filters or controller switching to the actor.
4. Select by full-duration compliant settling, then sustained hold, then effort. Test selected actors against the teacher on a new seed for 600 seconds, both nominal and with declared physical perturbations. Pass: arm violations measured over the entire rollout, final continuous holds, recovery after each kick, torque RMS/absolute effort/saturation and mechanical work; no inference clock or success freezing. Save bilingual human figures/report separately from machine records, source snapshots and reproduction settings. Release GPUs.

## Structure budget

Reuse EnvState, Actor, Critic, learner/replay/demonstration dictionaries and existing dynamics/teacher/launcher. No new classes or data classes. Independent objects: settings (experiment contract), state/traces (physical records), learner/replay (TD3 state), demonstrations/selection (qualified categorized data), metrics/figure (evidence).

- Existing `observe`: explicit stationary option returns physical five features, excluding clock and hold memory. Existing `initialize` chooses five inputs for v3; existing `update` uses v3 discount; existing pretrain reuses supplied discounted returns.
- New `RL/jax_stationary_task.py`: `targeted_resets` (four documented physical start distributions), `transition` (continuing dynamics and stationary integrated reward), `collect` (batched replay with reset/truncation semantics). One scan closure in transition. No helper class.
- New `RL/jax_stationary_evaluation.py`: `evaluate` (live batched policy rollout, metrics and saved physical traces, one scan closure). Existing long-rollout experiment and analyzer extend to targeted resets, five-feature actors, explicit perturbations and effort metrics; teacher logic remains unchanged.
- New `bringup/rotary_stationary_workflow.py`: `train` (validate v3, pretrain, collect/update, evaluate/checkpoint with progress), no new wrappers. Reuse Actor/Critic and TD3 optimizer code.
- New `experiments/stationary-balancing/prepare.py`: `main` reconstructs continuing rewards/discounted returns, categorizes transitions, splits episodes and writes balanced replay/manifest. One top-level artifact plotting recipe may combine results without new functions/classes.
- Existing launcher gains a stationary-training operation and snapshots new scripts. New test file has at most three substantive tests for stationary dynamics/observations, continuing bootstrap, and targeted data/teacher consistency.

New tunable parameter: discount per100 ms action, initially0.995 (roughly20-second discounted horizon). Reuse torque cost, arm cost, energy cost, upright widths, imitation weight, data fraction, network widths, exploration/target noise and update budgets. Fixed reset distributions and category balancing are defined in the protocol. New experiment metadata: reset_suite, perturbation_times_s, perturbation_delta. No new controller heuristics or action smoothing. Squared torque effort replaces absolute effort only in explicit v3. Physical observations20 ms, integration2 ms, control100 ms, arm±135°. Rollouts may reset at120 s for sampling, but the Bellman target remains nonterminal and uses the pre-reset next state.
